# 🛍️ LojaMVC

Sistema desenvolvido em **ASP.NET Core MVC**, utilizando a linguagem **C#** e o padrão arquitetural **Model-View-Controller (MVC)**.

O projeto tem como objetivo desenvolver um sistema de gerenciamento de uma loja, permitindo o cadastro e gerenciamento de **clientes e produtos** por meio de operações CRUD (Create, Read, Update e Delete).

A aplicação utiliza o **Entity Framework Core** para persistência dos dados, **SQL Server** como banco de dados e uma interface desenvolvida com **Bootstrap**, proporcionando uma aplicação organizada, responsiva e de fácil utilização.

## 🗄️ Banco de Dados

O banco de dados do sistema foi desenvolvido utilizando o **SQL Server**.

A aplicação utiliza o **Entity Framework Core** para realizar a comunicação entre o sistema e o banco de dados.

A estrutura do banco foi criada utilizando a abordagem **Code First**, juntamente com **Migrations** para criação e atualização das tabelas.

## ✨ Funcionalidades

### 👥 Clientes

O sistema permite:

- Cadastrar clientes
- Visualizar clientes cadastrados
- Editar informações dos clientes
- Excluir clientes
- Visualizar detalhes de um cliente
- Informar nome, e-mail e idade
- Definir se o cliente está ativo ou inativo

### 📦 Produtos

O sistema permite:

- Cadastrar produtos
- Visualizar produtos cadastrados
- Editar informações dos produtos
- Excluir produtos
- Visualizar detalhes dos produtos
- Gerenciar as informações dos produtos

### 🏠 Página Inicial

A página inicial apresenta:

- Identidade visual da LojaMVC
- Menu de navegação
- Acesso rápido aos clientes
- Acesso rápido aos produtos
- Interface personalizada com cores em tons de lilás

## 🎨 Interface

A interface foi desenvolvida utilizando:

- Bootstrap 5
- Razor Views
- HTML5
- CSS3
- jQuery
- Bootstrap Icons

O sistema possui uma identidade visual baseada em **tons de lilás e roxo**, buscando proporcionar uma interface moderna, simples e agradável.

Entre os elementos da interface estão:

- Barra de navegação personalizada
- Ícones para facilitar a navegação
- Botões estilizados
- Tabelas para exibição dos dados
- Formulários para cadastro e edição
- Cards e efeitos visuais
- Layout responsivo
